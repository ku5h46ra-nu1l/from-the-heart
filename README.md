# I Made This For You

An emotional, interactive apology website built with HTML, CSS, and vanilla JavaScript.

## 📖 Overview

This is a heartfelt interactive experience designed to apologize in a genuine way. It follows 11 sections that guide the user through the process of acknowledging a mistake, explaining without excuses, and ending gracefully.

## 🚀 Running

Just open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).

No build step, no dependencies. Just static files.

## 🎮 Features

- Animated star/particle background
- Interactive flip cards (Section 3)
- Before/after cards (Section 5)
- Mini-game with choices (Section 8)
- Music player with play/pause, volume, progress bar
- Floating hearts animation
- Cursor glow effect
- Hidden easter egg (look around!)

## 🌌 Sections

1. 🎧 Opening — "Before You Start"
2. 👀 "Okay... Let's Be Honest"
3. 💭 "What You Might Have Thought"
4. ❤️ The Actual Apology
5. 🔄 "What I Should've Done"
6. 🧠 "No Excuses"
7. 🌷 "Things I Appreciate About You"
8. 🎮 Mini Game — "Can We Fix My Communication Skills?"
9. 🎵 Music / Feelings Section
10. 💌 "One Last Thing"
11. 🌌 Final Screen

## 🛠️ To Customize

- **Text content**: Edit `index.html`
- **Styling**: Edit `style.css`
- **Interactions**: Edit `script.js`
- **Appreciation cards**: Edit Section 7 in `index.html` with personal details
- **Easter egg**: Located at bottom-right of Section 11

## ⚠️ Note on Music

The website will work without a music file, but the experience is enhanced with background music. Place your MP3 at `assets/music/song.mp3`.
